# 🏥 Health First Hospital Management System

> **"Your Health, Our First Priority."**

This is a Python-based hospital management system created as a **college project to apply and demonstrate the Python concepts I have learned.**

The project focuses on managing basic patient records and providing useful hospital-related information through a simple menu-driven system.

### Features

* Register new patients
* Add patient consultation details
* Search, update, and delete patient records
* Display patient details and consultation history
* View doctor information and specializations
* View hospital information
* Get basic health awareness tips

### Concepts Used

* Python Functions
* Lists
* Dictionaries
* Nested Data Structures
* Loops
* Conditional Statements

### How to Run

```bash
python hospital_management.py
```
